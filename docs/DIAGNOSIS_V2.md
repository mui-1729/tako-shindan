# 診断設計 v2 — 「他人からどう見えているか」

## 目的

学生がSNSで気軽に遊べる他己診断。本人の本質や能力を断定せず、**回答者が観察している行動傾向**と**関係性ごとの印象差**を楽しく可視化する。

- 診断リンク作成はログイン不要
- 回答前に関係性を2問、性格を8問（4択＋「わからない」）
- 16種類の動物キャラはシェアしやすい結果の見出し
- 本命の結果は「総合タイプ＋視点による違い」
- 心理検査やMBTIの正式な診断ではない

## 関係性（従来どおり）

- Q1: 親友 / 友達 / 恋人 / SNSの知り合い / 知り合い
- Q2: 回答者から見た立場 = 先輩 / 同期・同級生 / 後輩 / 該当なし

関係性はタイプの採点に使わず、回答後の比較のみに使用する。たとえば「後輩の親友」も、Q1で親友、Q2で後輩を選択できる。

## 新しい4軸と質問

| 軸 | 0点側 | 100点側 | 観察できる場面 |
| --- | --- | --- | --- |
| ① 会話の入り方 | 自分から話す | 様子を見て聞く | 複数人の会話・初対面 |
| ② 物事の進め方 | 試しながら | 準備してから | 予定変更・イベント準備 |
| ③ 物事の選び方 | 新しい方法 | 慣れた方法を磨く | 企画・改善 |
| ④ 助けるときの初動 | まず気持ちを聞く | まず具体策を考える | 相談直後・失敗直後 |

4軸を「能力の有無」ではなく**同じ場面での初動・好みの傾向**として表現する。「共感できる人は解決が苦手」といった誤った二者択一を避ける。

質問は各軸2問。選択肢に 0 / 33 / 67 / 100 を割り当て、半分の質問で選択肢の並びを反転させる。「わからない」は -1 として除外する。最低6/8問、かつ各軸1問以上を必須とする。

**弱点:** 各軸2問の短い娯楽診断なので、心理学的に妥当な性格判定を保証しない。50点付近はどちらの行動も観察される可能性があり、厳密なタイプ境界ではない。

## 最終結果：同じキャラでも印象が変わる

1. 個別結果：その回答者の4軸 → 動物
2. 関係性別：親友・友達などの集計 → 動物
3. 立場別：先輩・同期・後輩などの集計 → 動物
4. 最終結果：全員の回答を1人1票で平均 → 代表動物
5. 多面性プロフィール：比較可能なカテゴリ同士で差が最大の軸を示す

**多面性ラベル（暫定の演出）**
- 各カテゴリ3人以上が2グループ以上あり、最大差20点以上 → 「いろんな顔を持つタイプ」
- 比較ができ、最大差が20点未満 → 「どこでも自分らしいタイプ」
- 比較人数不足 → 「これから見えてくるタイプ」

このラベルは心理学的な指数ではなくエンタメの演出。集計カテゴリの回答人数が異なれば比較は偏りうる。属性の組合せを細かく絞ったグループはMVPでは表示しない。

## 個人情報・安全と互換性

- 個別の生回答は保存せず、回答者IDのハッシュと累積スコアのみを保存
- 回答者側も診断される本人の個別回答を閲覧できない
- 総合結果・各カテゴリは3人以上のときだけ公開
- 管理者専用URLには秘密トークンが必要
- **旧リンク(v1)は元の質問・採点を維持**、新規発行リンクのみv2の質問とキャラを使用
- DBに「診断バージョン」を別テーブルで保持。旧リンクにはそのレコードがないのでv1と判定
- 匿名荒らし対策・回答削除・公開前の総合動作検証は別途必要

## 今後の検証

10〜20人規模で「答えにくい質問」「タイプが似すぎる」「回答人数によるブレ」を確認。必要なら8問→12問の追加も検討。質問文の改善時にも、保存済みの回答と混ざらないよう必ずバージョンを分ける。
